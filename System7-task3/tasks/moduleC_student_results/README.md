# Module C Practical Task – Predict Student Results with a Neural Network

## Goal
Predict each student's final score from study habits and background, using a Keras neural network, and check whether the network beats a simple linear regression baseline.

## Data
`tasks/data/students.csv` (generated by `tasks/data/generate_students.py`). Features: study hours, attendance, previous score, sleep hours, practice tests, on-time assignments, school type. Target: `final_score` (0–100).

## Steps the script performs
1. Load the data, one-hot encode `school_type`, split 60/20/20 (train/validation/test) and scale on the training set.
2. Train a linear regression baseline.
3. Build, compile and train a neural network with early stopping.
4. Compare both models on the test set (MAE, RMSE, R²) and save the learning curve.
5. List the largest prediction errors to see where the model struggles.

## Run
```bash
python tasks/moduleC_student_results/predict_student_results.py
```

## Deliverables
- The comparison printed by the script and `learning_curve.png`
- `RESULTS.md` in this folder: which model you chose and why, the number of epochs before early stopping, and one change you would try next (for example, more units, dropout, or a different learning rate).

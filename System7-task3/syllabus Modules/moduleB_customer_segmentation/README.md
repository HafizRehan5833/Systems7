# Module B Practical Task – Customer Segmentation

## Goal
Group customers into segments using clustering, describe each segment in plain language, and recommend one action per segment.

## Data
`tasks/data/customers.csv` (generated by `tasks/data/generate_customers.py`). Columns: age, annual income, spending score, visits per month, average basket value, tenure in months.

## Steps the script performs
1. Load and scale the features (clustering is distance-based, so scale matters).
2. Choose k for K-Means by silhouette score.
3. Compare K-Means, hierarchical (agglomerative) clustering and DBSCAN with silhouette scores.
4. Project the customers to 2D with PCA and save a cluster plot.
5. Profile the K-Means segments (mean of each feature) and save `segments_summary.csv`.

## Run
```bash
python tasks/moduleB_customer_segmentation/segment_customers.py
```

## Deliverables
- `segments_summary.csv` and the cluster plot (created by the script)
- `SEGMENTS.md` in this folder: one name and one recommended action for each segment, plus a sentence on why you chose your final algorithm.

## Note on the results
On this synthetic data, K-Means, hierarchical clustering and DBSCAN find exactly the same groups (the script's silhouette scores match). The four segments are well separated. To see the algorithms disagree, increase the `SPREAD` values in `tasks/data/generate_customers.py`, regenerate the data, and run the script again.

AI, MACHINE LEARNING, DEEP LEARNING, AND DATASET TERMS
Project: Mobile-Based Food Quality Detection and Classification App Using Deep Learning

1. ARTIFICIAL INTELLIGENCE (AI)
Artificial Intelligence (AI) is a branch of computer science that enables machines to perform tasks that normally require human intelligence, such as recognizing objects, understanding language, solving problems, and making decisions.

Example in this project:
AI helps the application analyze a food image, identify the food item, and provide relevant information about its quality and nutritional value.

2. MACHINE LEARNING (ML)
Machine Learning (ML) is a subset of AI that allows computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

Example in this project:
A machine learning model learns from labeled food images to distinguish between different food categories.

3. DEEP LEARNING (DL)
Deep Learning (DL) is a subset of machine learning that uses artificial neural networks with multiple layers to learn complex patterns from large amounts of data.

Example in this project:
A deep learning model such as EfficientNetB0 can learn visual features from food images and predict the food category. With a separately labeled dataset, it can also learn to classify visible food quality.

Relationship:
- Artificial Intelligence is the broad field of intelligent machines.
- Machine Learning is a subset of AI that learns patterns from data.
- Deep Learning is a subset of ML that uses multilayer neural networks.

4. TYPES OF MACHINE LEARNING

A. SUPERVISED LEARNING
Definition:
Supervised learning is a type of machine learning in which a model learns from labeled data. Each training example contains an input and its correct output.

Example in this project:
- Input: An image of a fresh apple.
- Label: Apple — Fresh.
- The model learns visual patterns associated with the provided label.
- The model predicts the category of a new image.

Supervised learning can support food recognition and visible-quality classification when the training data contains the appropriate labels.

B. UNSUPERVISED LEARNING
Definition:
Unsupervised learning is a type of machine learning in which a model finds patterns, similarities, or groups in data without predefined labels.

Example in this project:
An unsupervised algorithm could group food images according to visual similarities, such as color, texture, and shape, without initially knowing which images represent apples or bananas.

Important:
These groups do not automatically indicate whether food is fresh or spoiled. Human interpretation or labeled examples would be needed to establish that meaning.

C. REINFORCEMENT LEARNING
Definition:
Reinforcement learning is a type of machine learning in which an agent learns to make decisions by interacting with an environment and receiving rewards or penalties.

Example in this project:
A future version of the application could use reinforcement learning to improve personalized dietary recommendations based on a defined reward system and user feedback.

Important:
Reinforcement learning is not necessary for the core food-image classification system. Supervised deep learning is the more direct approach.

Summary:
- Supervised learning: Learns from labeled examples; for example, classifying food images.
- Unsupervised learning: Finds patterns without labels; for example, grouping visually similar foods.
- Reinforcement learning: Learns through rewards and penalties; for example, optimizing recommendations.

5. IMPORTANT DATASET TERMS

DATASET
A dataset is an organized collection of data used to train, validate, test, or evaluate a machine learning model.

In this project, the dataset may contain food images and their corresponding food-category labels, plus separate quality labels where available.

DATA / SAMPLE
A single record or example in a dataset. In this project, one food image can be one sample.

FEATURE
An attribute or piece of information used by a model. For image classification, features can include learned patterns such as shape, color, edges, and texture.

LABEL
The correct category assigned to a sample, such as Apple, Banana, Fresh, or Visibly Spoiled. Quality labels must be supported by quality-annotated images.

TRAINING DATASET
The portion of data used by the model to learn patterns.

VALIDATION DATASET
Data used during development to compare models and tune settings.

TESTING DATASET
Separate data used to evaluate the trained model on previously unseen examples.

CLASS
A category the model predicts, such as Apple, Banana, or Orange.

CLASS IMBALANCE
A situation in which some classes have many more samples than others.

DATA AUGMENTATION
Creating modified training images, such as rotated or flipped versions, to improve robustness.

PREPROCESSING
Preparing images before model input, for example resizing them to the required dimensions and normalizing pixel values.

EPOCH
One complete pass through the training dataset.

BATCH SIZE
The number of training samples processed together before a model update.

OVERFITTING
When a model performs well on training data but poorly on new images.

ACCURACY
The proportion of predictions that are correct.

MODEL
The trained computational system that makes predictions from input data.

6. EXAMPLE OF DATASET SPLITTING

Suppose the dataset contains 10,000 labeled food images. An illustrative split could be:

- Training: 70% = 7,000 images. Used to learn patterns.
- Validation: 15% = 1,500 images. Used to tune the model.
- Testing: 15% = 1,500 images. Used for final evaluation.

These numbers are examples only. The actual split depends on the dataset and project design. Images from the same source or near-duplicate images should not leak across splits, as this can make evaluation misleading.
